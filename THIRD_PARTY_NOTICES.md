## Classimax Bootstrap

Parts of the catalogue information architecture—product-style cards, list rows,
filter widgets, and the two-column detail layout—were adapted from the component
patterns in **Classimax Bootstrap** by Themefisher.

- Upstream: https://github.com/themefisher/classimax-bootstrap

project-specific CSS and vanilla JavaScript. Classimax demonstration images and
classified-advertising content are not included. The upstream README explicitly
